# no-lead-left-behind

An AI agent deployment for a fictional residential developer: buyers get answers in Telegram in seconds, every conversation becomes a CRM lead, and phone calls land on the lead as a short summary with personal data removed.

Work in progress. The full case study (problem, before/after, architecture, limits) will be here.

Why plain Python, not n8n: one webhook and one CRM fit in a few tested lines; n8n pays off when a client's team edits many integrations without a developer.
