# Issue tracker

For the Matt Pocock skills (to-spec, to-tickets, implement, code-review).

- **The spec** is `delivery/spec.md` plus `delivery/test-cases.md`.
- **Tickets** are the numbered steps under `## Steps` in `docs/PLAN.md`: one step per ticket, each with its check and the steps that block it. No separate ticket files, no GitHub issues.
- **"Publish to the tracker"** means: write or update the step in `docs/PLAN.md`.
- **Triage labels** are not used.
- **The glossary** is `GLOSSARY.md` (the skills call it `CONTEXT.md`). Decisions go to `docs/adr/`.
