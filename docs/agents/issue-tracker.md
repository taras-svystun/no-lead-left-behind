# Issue tracker

For the Matt Pocock skills (to-spec, to-tickets, implement, code-review).

- **The spec** is `delivery/spec.md` plus `delivery/test-cases.md`.
- **Tickets** are the items T1, T2, … under `## Tickets` in `docs/PLAN.md`, each with its why, check and the tickets that block it. No separate ticket files, no GitHub issues.
- **"Publish to the tracker"** means: write or update the ticket in `docs/PLAN.md`.
- **Triage labels** are not used.
- **The glossary** is `GLOSSARY.md` (the skills call it `CONTEXT.md`). Decisions go to `docs/adr/`.
